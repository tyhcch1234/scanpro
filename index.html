技術說明

這個頁面完全在你的瀏覽器本機運算，相片不會上傳到任何伺服器。以下是各項功能實際使用的演算法，以及哪些是真正還原、哪些是可調參數的近似處理。

完整實作的電腦視覺

  • 自動邊緣偵測：灰階 → 高斯模糊 → Sobel 梯度 → 自適應門檻二值化 → 3×3 膨脹 → 連通域分析，取最大輪廓後用 min/max(x+y)、min/max(x−y) 求四個極值角點；多組門檻各跑一次，取面積最大且通過凸性／面積／邊長檢查的候選。
  • 透視校正：由四組對應點解 8 參數單應性矩陣（高斯消去法），對每個輸出像素做逆映射 + 雙線性取樣，梯形自動還原成正面矩形。
  • 智慧去陰影：取亮度低頻背景（降採樣 → 大核 box blur → 雙線性升採樣），再以 輸出 = 原像素 × 目標白 / 背景亮度 做除法正規化，同時保留色相。這是文件掃描的經典做法，對側光、手影、燈泡暗角都有效。
  • 黑白高對比：局部自適應二值化（半徑隨解析度縮放），再去除孤立雜點，把透印字跡、紙張紋理一併濾掉。
  • 除噪：亮度通道 3×3 中值濾波，只回寫亮度差，避免色偏。
  • 去摩爾紋：轉 YCbCr，僅對 Cb/Cr 色度通道做低通，消除翻拍螢幕的彩色網格，同時保住文字銳利度。
  • 銳化：反銳化遮罩（unsharp mask），以亮度差回寫 RGB。
  • 修補筆刷：筆刷遮罩 → 影像金字塔 push-pull 擴散填補，用周圍紙張色補回被遮住的區域。

近似處理（可調參數，非生成式 AI）

  • 曲面展平：真正的書頁 3D 重建需要文字行彎曲模型或深度網路。這裡改用「水平非線性重映射」（x' = W·t^(1+k)）＋可調滑桿，讓你把裝訂處被壓縮的內容拉回來。對輕微彎曲很有效，嚴重捲曲仍需要專業工具。
  • 超高解析度：以雙三次插值 + 反銳化遮罩放大，屬於訊號層面的重建，不是生成式超分模型（那種需要數十 MB 的神經網路權重）。
  • 去褶皺／去污漬：靠去陰影 + 自適應二值化 + 對比拉伸壓掉淺色污漬，深色污漬請用修補筆刷手動圈選。

PDF 產生

沒有使用任何第三方函式庫。頁面由 JS 直接組裝 PDF 物件樹、xref 表，並把畫布輸出的 JPEG 以 /DCTDecode 內嵌成影像 XObject，因此檔案小、開啟快、可直接列印。
