# ScanPro — 相片轉 PDF 掃描網頁

**線上版：<https://tyhcch1234.github.io/scanpro/>**

把幾張手機拍的相片，變成一份乾淨、端正、可直接列印的 PDF。
純前端、零依賴、不需伺服器，**雙擊 `index.html` 就能用**，所有運算都在本機瀏覽器完成，相片不會離開裝置。

單檔版：[`single.html`](single.html)（CSS/JS 全內嵌，112 KB，適合直接傳給別人）。

## 快速開始

1. 用 Chrome / Edge / Safari 開啟 `index.html`
2. 點「拍照掃描」或「從相簿選擇」，一次選多張
3. 每張自動偵測紙張邊界 → 自動透視校正 → 自動去陰影
4. 需要時點縮圖進編輯器微調（四角、濾鏡、修補筆刷）
5. 按「匯出 PDF」

手機上「拍照掃描」會直接開啟系統相機，拍完可以連續再拍，最後一次匯出。

## 功能對照

| 需求中的功能 | 這個網頁的做法 | 類型 |
|---|---|---|
| 自動邊緣偵測 | 灰階 → 模糊 → Sobel 梯度 → 自適應門檻 → 膨脹 → 連通域 → 極值角點；多組門檻取最佳候選，再以「邊緣吸附 + 直線擬合」精修 | 真實演算法 |
| 透視校正 | 8 參數單應性矩陣（高斯消去）＋ 雙線性逆映射重採樣 | 真實演算法 |
| 曲面展平 | 水平非線性重映射 `x' = W·t^(1+k)`，滑桿手動校正 | 近似（非 3D 重建） |
| 智慧去陰影 | 低頻背景估計 → 除法正規化（保留色相） | 真實演算法 |
| 手指痕跡擦除 | 筆刷圈選 → 影像金字塔 push-pull 擴散填補 → 對齊周圍紙色 | 半自動（需圈選） |
| 去褶皺／去污漬 | 去陰影 + 自適應二值化 + 對比拉伸壓掉淺色污漬 | 近似 |
| 螢幕摩爾紋抑制 | YCbCr 色度通道低通，只殺彩斑、不動文字 | 真實演算法 |
| 透字雜訊抑制 | 局部自適應二值化（半徑隨解析度縮放）＋ 去孤立雜點 | 真實演算法 |
| 多種濾鏡 | 增強並銳化 / 黑白高對比 / 灰階 / 魔幻彩色 / 省墨 / 原圖 | 真實演算法 |
| 超高解析度重建 | 雙三次插值 + 反銳化遮罩放大 | 近似（非生成式超分） |
| 多張合併 PDF | 自製 PDF 產生器，JPEG 以 `/DCTDecode` 內嵌 | 真實實作 |

> 真正的生成式修補與超解析需要數十 MB 的神經網路權重，無法塞進單一離線網頁；這裡改用可解釋的經典電腦視覺，效果對「文件掃描」這個場景已經足夠。App 內的「技術說明」也有同一份清單。

```
scanpro/
├── index.html          入口
├── css/style.css
├── js/
│   ├── cv.js           邊緣偵測、單應性變換、旋轉、展平、修補、邊框修剪

```

## 部署

推送到 `main` 後由 GitHub Actions 自動發佈到 GitHub Pages（`.github/workflows/pages.yml`）。
首次部署需要在 **Settings → Pages → Source** 選擇 **GitHub Actions**。

改動原始碼後若要更新單檔版：

```bash
python3 build_single.py     # 產生 single.html
```

## 測試

```bash
python3 tests/make_photo.py        # 產生 3 張模擬拍攝相片（桌面背景 + 透視 + 側光）
python3 tests/ui_test.py           # 邊緣偵測準確度、UI 流程、PDF 產出
python3 tests/interaction_test.py  # 修補筆刷、旋轉、全部套用預設
```

實測（1500×2000 合成相片，紙張四角已知）：

- 邊緣偵測最大角點誤差 **0.37 % – 0.41 %**（約 6 px / 1500 px）
- 單頁 1100 px 預覽渲染 **約 200–300 ms**
- 3 頁 A4 PDF 約 **520 KB**，`pdfinfo` 驗證通過、3 頁、正確尺寸

## 效能與限制

- 匯出解析度上限 2200 px（最長邊），平衡清晰度與記憶體
- 一次處理 20 頁以上時，編輯器會逐頁解碼，記憶體佔用可控（只保留縮圖）
- 相機即時預覽需要 HTTPS 或 localhost；從檔案直接開啟時，「拍照掃描」改用系統相機 App，一樣可以拍完回傳
- 輸入支援 JPEG / PNG / WebP / HEIC（Safari）
